# PentoGIS brand kit

The mark is a pentagon cut into five parcels. "Pento" means five, and a parcel split is the basic act of mapping and planning. One wedge is gold, and the other four step from dark to light steel.

## Files

| File | Use |
|---|---|
| `svg/pentogis-logo-dark.svg` | Primary horizontal logo on dark backgrounds |
| `svg/pentogis-logo-light.svg` | Primary horizontal logo on light backgrounds |
| `svg/pentogis-icon-dark.svg`, `svg/pentogis-icon-light.svg` | Icon only (nav bar, app tiles, stamps) |
| `svg/pentogis-logo-mono-black.svg`, `svg/pentogis-logo-mono-white.svg` | One-colour logo for print, embossing, fax, watermarks |
| `svg/pentogis-icon-mono-black.svg`, `svg/pentogis-icon-mono-white.svg` | One-colour icon |
| `svg/favicon.svg` | Browser tab icon (modern browsers) |
| `png/favicon-32.png`, `favicon-180.png`, `favicon-192.png`, `favicon-512.png` | Fallback favicon, Apple touch icon, Android and PWA icons |
| `png/pentogis-social-avatar-1024.png` | Profile picture for LinkedIn, X, GitHub, Google Business |
| `png/pentogis-og-banner-1200x630.png` | Link preview image (Open Graph and Twitter card) |
| `png/*` (logo and icon) | Ready-made PNGs for slides, Word and email signatures |

All wordmark lettering in the SVG files is converted to outlines, so the logos look the same everywhere with no font installed.

## Colours

| Name | Hex | Use |
|---|---|---|
| Obsidian | `#0b0f14` | Main dark background, text on light |
| Champagne gold | `#d4b06a` | Accent on dark |
| Deep gold | `#a8843f` | Accent on light (better contrast) |
| Off-white | `#e8e6df` | Text on dark |
| Steel | `#445771` to `#7f93ad` | Secondary shapes on dark |
| Slate | `#6f7681`, `#8a8f98` | Tagline and small text |

## Typography

Inter (free, Google Fonts). Wordmark: Inter Medium, all caps, letter-spacing 0.2em. Tagline: Inter Regular, all caps, tracked to match the wordmark width.

## Rules

- Clear space: keep at least the height of one gold wedge free on every side.
- Minimum size: icon 16 px, full logo 120 px wide. Below that, use the icon alone.
- Use the dark logo on dark backgrounds and the light logo on light ones. On photos or busy backgrounds, use the mono white or mono black.
- Don't stretch, rotate, recolour, add shadows, or put the logo on a background close to its own colours.
- Don't swap the gold wedge to another position.
