Coordinates

Coordinate converter

Paste a latitude and longitude in any common format to get decimal degrees, degrees-minutes-seconds, degrees and decimal minutes, and UTM (WGS84).

Examples: 40.7128, -74.0060 · 40°42'46"N 74°0'22"W · N40 42.767 W74 0.360

Need coordinates cleaned up for a whole dataset? We can help.

Map scale

Map scale converter

Turn a representative fraction like 1:24,000 into a verbal scale ("1 inch = 2,000 feet"), or the other way round. Add a ground distance to see how long it will be on the map.
